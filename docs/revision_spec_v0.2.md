# 改訂仕様 v0.2（データ基盤・修正項目・銘柄選別）

利用者が確定した仕様の保存版。**正本データは J-Quants Standard（有料・10 年）のみ**。無料代替の妥協はしない。

## 0. データ基盤の方針

- 正本は J-Quants API V2（Standard）。Stooq／yfinance／Perplexity の未検証 CSV は、正本・検証用データに混ぜない。混ぜた結果は「暫定（異種ソース混在データ）」と表示し、予測台帳に記録しない。
- J-Quants 由来のデータ（生データ・加工後の Parquet／DuckDB）は `data/jquants/` に完全分離する（git 管理外）。モデル側とはアダプタ（`forecastlib/jquants_adapter.py`）で疎結合にする。
- 生の J-Quants 表は、外部 LLM・公開レポートに出さない。出すのは件数・列名・ハッシュ・検証結果・集計のみ。
- 解約時は、データと派生 DB を削除する。`scripts/jquants/purge.sh --yes` の 1 コマンドで全消去できること。
- 立花証券 API は、日中・約定の補助だけに使う。過去データの取り込みには使わない。
- Standard 固有のデータ（信用残・空売り比率・業種別指数など）は、保存スキーマだけ用意する。モデル入力は、事前登録した除去実験（ablation）を通した後に限る。

## C. W5 の事前固定仕様（銘柄選別と売買）

- 4 層: 確率予測／銘柄選別／売買とサイズ／評価。
- 21 営業日固定のリバランス: T の引け後に順位付け → T+1 始値で買い → T+22 始値で売り（入れ替え）。対象は上記の母集団に、履歴 500 営業日以上を加える。ストップ高・安で約定できない場合は、執行台帳で扱う。
- 仮想資金 1,000 万円、上位 15 銘柄、100 株単位、現金の利息は 0%。最初は等ウエイト。次に逆ボラ重み（w_i ∝ 1/σ̂3,i、上限は等ウエイトの 2 倍）と高ボラ局面の現金ゲートを、別々に比較する。現物の買いのみ（信用・空売り・レバレッジなし）。価格での利確・損切りの最適化はしない。
- ラベル: Open_{T+22}/Open_{T+1}−1（分割調整済み）から、同期間の TOPIX 価格リターンを引く。片道コストは 0／10／15（基準）／30 bps。
- 比較対象: TOPIX 価格指数、同日・同母集団の等ウエイト平均。
- モデル:
  - SEL-A（チャートのみのリッジ）: 価格・出来高の特徴量、ボラ収縮率（5 日 GKYZ ÷ 22 日 GKYZ）、52 週高値への近さ C/max H252、TOPIX 下落日の耐性。
  - SEL-B（財務ベースのリッジ）: 会社予想の営業利益・純利益の上方修正率（経過日数で減衰）、配当予想の変更、予想 PER／PBR または益利回り・簿価利回り、ROE。開示時刻に基づく。
  - SEL-C（結合）: SEL-C1 は線形リッジの結合、SEL-C2 は LightGBM（深さ 2〜3）で、上方修正 × ボラ収縮 × 高値近接 などの交互作用。
- 21 営業日の窓に決算発表を含む保有銘柄は、フラグを付ける。
- 採用ゲート: 売買台帳が 3 ケース（単一銘柄の買い持ち／等ウエイト保有／定期入れ替え）で 1 円単位まで一致する。コスト 15 bps 後の上位 15 の年率超過収益が、TOPIX と母集団平均の両方に対して正で、特定の 1 年や少数の急騰に依存しない。全試行を試行台帳に記録し、DSR／PBO を算出する。
