# 日本語の学術文献（テクニカル分析・売買ルール・投資家行動・制度）— CiNii Research・J-STAGE で確認した論文
> 要約: 日本語で書かれた、テクニカル分析・売買ルール・モメンタム／リバーサル・出来高・投資家行動・値幅制限／空売り規制・バックテスト過学習に関する論文を、CiNii Research と J-STAGE で探し、抄録欄を読んだ39件（うち2件は抄録欄が目次または導入の冒頭だけ）と、書誌のみ確認した21件を整理した（確認日 2026-11-11）。J-STAGE の論文ページを取得して抄録を読めたのは12件で、残る27件は CiNii の OpenSearch 応答の抄録による。本文は読んでいない。
> データ・スヌーピングを考慮したテクニカル分析の検証を題名に掲げる論文（北島 2011）はあるが、抄録を取得できず内容は未確認である。抄録を読めた範囲では、補正つきで株式のテクニカルルールを大規模に検証した日本語論文は確認できなかった。抄録を読めた報告は、工学系の「提案手法のシミュレーション」が多く、取引コスト・多重検定・標本外の扱いが抄録に書かれていないものが大半である。結論は一様でなく、有効とする報告と、効果の縮小や低い正解率を示す報告が併存する。
> 日本株の価格モメンタム／リバーサルや処分効果の中心的な日本語論文（徳永、加藤・宮崎、城下・森保、閻石ら）は、抄録を許可ホストで取得できず、書誌のみの確認にとどまる。教育目的であり、売買の推奨ではない。
> 最終更新: 2026-11-11

## 1. 要約

- **範囲**: CiNii Research の OpenSearch（論文）に題名・キーワード語で29回の検索を行い（結果を使ったのは21回）、J-STAGE の論文ページ12件を取得した（方法と制限は [../08_primary_sources/02_ndl_cinii_jstage.md](../08_primary_sources/02_ndl_cinii_jstage.md)）。抄録欄を読んだ39件を §4.1〜§4.6 に、抄録がなく書誌だけ確認した21件を §4.7 に置いた。
- **テクニカルルールの有効性**: 実データで株式のルールの収益性を示した日本語論文として抄録を読めたのは佐藤（2017）の移動平均乖離率ペアトレードで、取引コストを考慮しても市場効率性の反例とみる[PB-201]。一方、竹原（2012）は取引コストの低下で既存アノマリーのリスク調整後リターンが縮小しうると述べ[PB-202]、後藤ほか（1988）は専門書のチャート分析ルールの正解率を約35〜45%と報告した[PB-204]。期間・市場・評価基準・コストの扱いが異なり、直接は比べられない。
- **工学系の提案手法**: 遺伝的アルゴリズム、ニューラルネット、CNN（ローソク足画像）、一目均衡表を入力にした予測、LLM による戦略生成などが多い（§4.2）。多くが「提案手法の有効性を確認した」と述べるが、抄録に成績の数値がないか、的中率（収益ではない）の報告で、過剰適合や多重検定の扱いは書かれていない。
- **モメンタム・出来高・季節性**: 出来高の増加後に株価モメンタムが続く関係が、ニュースの有無によらず残り、投資家のトレンド追随で説明できるとする報告[PB-222]、日経225の強気転換が年前半に多い（「デカンショ節」）とする報告[PB-224]、残差リターンのリバーサル戦略のバックテスト[PB-225]がある。
- **投資家行動**: 海外投資家と信用取引の個人投資家の資金流入が大きい局面でボラティリティ・アノマリーやバリュー・アノマリーが弱まるとする報告[PB-227][PB-228]、PEAD とアンカリングの関連[PB-229]がある。処分効果の日本語文献は書誌のみ（§4.7）。
- **制度**: 値幅制限・空売り規制は人工市場シミュレーションが中心で、結論は仮定に依存する[PB-232][PB-233][PB-234][PB-235][PB-236]。
- **検証方法**: バックテストの「裏切り」[PB-238]、バックテスト→実践投入の反復による最適化の不安定[PB-239]、検出力較正のパラメータ化依存[PB-240]を扱う日本語論文がある。

## 2. 調べ方と読み方

- 検索: CiNii Research の OpenSearch（`articles`）に、テクニカル分析、一目均衡表、ローソク足、値幅制限、モメンタム、リターン・リバーサル、ディスポジション効果、アンカリング、データ・スヌーピング、出来高、空売り規制、バックテスト、アノマリー、曜日効果、ボリンジャーバンド、投資部門別、順張り、ランダムウォーク、トレンドフォローなどを投げた（[PB-040]〜[PB-060]）。`q` は題名・キーワード中心の一致とみられ、長い語句は 0 件になる。再現手順は 08 文書。
- 選定: 日本語で書かれ、日本の市場・制度・投資家を扱うか、日本語でテクニカル分析・売買ルール・検証方法を論じる論文を、題名と抄録から選んだ。査読誌論文、学会の予稿・講演要旨、研究会資料、大学紀要が混在する。**媒体の違いで証拠の強さが変わる**ので、注意点欄に頁数や種類（予稿・短報など）を書いた。
- 検証区分 ✅P: J-STAGE の論文ページ（12件）または CiNii の OpenSearch 応答の該当レコード（27件）を取得し、書誌（題名・著者・誌名・巻号頁・DOI）と抄録を照合した。CiNii の書誌レコード JSON は WAF の判定（HTTP 202）で取得できなかったので、CiNii の URL（`https://cir.nii.ac.jp/crid/…`）は識別子として示すにとどまる。**本文は読んでいない**。「抄録の言い換え」は筆者の要約で、抄録そのものではない。
- 抄録の質: 抄録欄が目次だけ・導入の冒頭だけの記録がある（時永 1995、翟 2022）。その場合は、確認できた範囲だけを書いた。
- 「筆者注」は筆者の推論で、論文の主張ではない。数値は抄録の記載のとおりで、本文との照合はしていない。

## 3. テーマ別の整理

### 3.1 テクニカル分析・売買ルールの検証

- 肯定的な報告: 佐藤（2017）は、TOPIX Core30 の銘柄で、25日移動平均乖離率の差を AR(1) に当てはめて平均回帰の速い組を選ぶペアトレードが、2002年1月〜2016年6月に比較対象を上回る収益率を示したと述べる[PB-201]。水野ほか（2006）は、グランビルの法則とウェーブレット解析の併用が単独より良く、別の30銘柄への適用で平均利得36%だったと報告する[PB-205]。
- 効果が弱い・縮小を示す報告: 後藤ほか（1988）は、グランビルの法則やローソク足などをルール化した結果、「2か月以内に5%以上動けば正解」の基準で各手法の正解率が約35〜45%だったと述べる[PB-204]。竹原（2012）は、東証の流動性の上昇・取引コストの低下の下で、既存アノマリーの一部ではリスク調整後リターンが縮小しうると示す[PB-202]。
- 評価: 条件が異なる（期間、銘柄、評価基準、コストの扱い）ので、肯定と否定を一つの尺度で並べることはできない。補正後に効果が弱まる英語圏の報告（[01_academic_literature.md](01_academic_literature.md)、日本株は [EV2-046]・[EV2-047]・[EV2-048]・[EV2-049]）との整合は、佐藤（2017）の標本期間・補正の有無を本文で確認するまで保留とする。
- 補正を扱う論文: 北島（2011）は題名にデータ・スヌーピングと Reality Check の語（キーワード）を持つが、抄録を取得できず、結論は未確認（§4.7）。
- 弱い証拠の特徴: 1〜2頁の予稿、抄録に数値がない、tick・分足の予測（日足のルールへ一般化できない）、単一の指数。

### 3.2 機械学習・進化計算・LLM によるルール生成

- 遺伝的アルゴリズムで移動平均のクロス前に売買する提案[PB-211]、ニューラルネットでクロスを事前に予測する提案[PB-212]、GNP による売買ルール生成[PB-213]、戦略木の進化計算[PB-214]、CNN による株価予測[PB-217]、ローソク足の画像を入力にした CNN[PB-218][PB-219]、一目均衡表を入力にしたニューラルネット[PB-220]がある。
- 抄録は「有効性を確認した」と述べるが、成績の数値を書かないものが多い。数値があるのは tick の的中率（IBM 株で80%以上、8銘柄平均65%）[PB-216]で、これは収益性ではなく日本株でもない。
- 2026年の報告[PB-221]は、LLM が TOPIX 500 構成銘柄のロングショート戦略をバックテストの結果から繰り返し直す枠組みを調べ、改善案が成績向上につながらない場合もあったと述べる。バックテストを反復して直す手続きは多重検定・過剰適合の影響を受けやすい（筆者注）。
- 抄録にデータ漏えい、多重検定、取引コストの扱いの記載はない。判断には [02_methodology_behavioral_japan_ml.md](02_methodology_behavioral_japan_ml.md) の D 節・E 節の注意が当てはまる。

### 3.3 モメンタム・リバーサル・出来高・季節性

- 出来高: 三輪・植田（2009、2010）は、出来高の増加後に株価モメンタムが続く関係が、重要ニュースがない場合でも強く残り、投資家のトレンド追随行動で説明しうると示す[PB-222][PB-223]。出来高を持続の手がかりにするチャート分析の考え方に、行動面の説明を与える（筆者注）。
- 季節性: 山崎・岡田（2014）は、日経225の強気転換が年前半に有意に多いとし、「デカンショ節」を市場心理で説明する見方と整合的とする[PB-224]。英語文献の [EV2-060] と同系統の主題。
- リバーサル: 渡部ほか（2026）は、残差リターンを使ったリバーサル戦略のバックテストでシャープレシオが改善したとする[PB-225]。翟（2022）は急落・急騰後の短期リバーサルを扱うが、CiNii の抄録欄は導入の冒頭だけで結果を確認できていない[PB-226]。
- 日本株の価格モメンタムが弱く逆張りが有利とする英語文献（[EV2-050]・[EV2-053]）と方向は整合的に見えるが、日本語の中心的な論文（徳永 2009、加藤・宮崎 2006、城下・森保 2007、ジン 2023、岩永 2021、高橋 2004）は抄録を取得できず、内容は未確認（§4.7）。

### 3.4 投資家行動・アノマリー

- 岩澤・内山は、海外投資家と信用取引の個人投資家からの資金流入が大きい局面で、ボラティリティ・アノマリー[PB-227]やバリュー・アノマリー[PB-228]が消滅・減衰し、流出局面で強まると報告する。需給主体のフローがアノマリーの強弱と結びつく、という材料であり、チャートの売買ルールの検証ではない。
- 松村（2010）は、日本市場の PEAD が主要なファクター・モデルでは説明できず、投資家が直近の決算情報を過小評価して徐々に修正していると示す[PB-229]。価格が情報を遅れて織り込むことは、トレンドが続く理由の候補になるが、チャートのトレンドフォローの収益性を検証したものではない（筆者注）。
- 処分効果（ディスポジション効果）の日本語文献（閻石 2007・2010・2011、米澤・中井 2012）は書誌のみで、高橋ほか（2009）の IPO 後の出来高と処分効果の検討も、抄録は目的しか述べない[PB-230]。英語文献は [EV2-057]・[EV2-059]。

### 3.5 制度（値幅制限・空売り規制）

- 人工市場: 値幅制限は条件により急変動を抑えるが、制限が注文取消しの時間より短いと注文が制限価格付近にたまり、サーキットブレイカーより劣る[PB-232]。規制がないとバブル崩壊時に価格が行き過ぎ、値幅制限はこれを防ぎうるが、空売り規制とアップティックルールは価格を理論価値より高くする[PB-233]。情報入手速度に差があると、値幅制限は常に安定化するとは限らない[PB-234]。
- 空売り規制: 理論モデルでは、適切なタイミングの一時的な規制が価格の安定化に貢献する[PB-235]。人工市場では、短期には下落を抑えるが、長期に及ぶとバブルを形成して安定化を妨げる[PB-236]。2013年3月の見直しをイベントとした VAR 分析[PB-237]もあるが、抄録は結果の方向を述べない。
- 評価: 結論は人工市場・理論モデルの仮定に依存し、東証の実際の値幅（基準値段別）や空売り規制の細目に当てはめた検証ではない。英語文献は [EV2-054]・[EV2-055]。現行制度は [../02_japan/04_tse_market_rules_and_chart_effects.md](../02_japan/04_tse_market_rules_and_chart_effects.md) と JPX の一次資料で確認すること。

### 3.6 検証方法（バックテスト過学習）

- 野村（2016）は、バックテストの成績が良くても実運用で失敗する「バックテストの裏切り」を避ける手段として、フォワードテストとミレニアムテストを提案する[PB-238]（提案者自身の戦略への適用）。
- 水田ほか（2022）は、人工市場で、バックテストで最適パラメータを探す参加者が1人いるだけで、最適化が収束せず価格も不安定になることを示す[PB-239]。
- 夏川（2026）は、バックテスト過学習の評価法を検証するための検出力較正で、信号の注入方法のパラメータ化によって臨界強度の比が約35倍から約1.6倍まで変わることを示し、共通の効果量の併記を勧める[PB-240]（合成データ）。
- 『統計』誌に Bailey・López de Prado らの「バックテストのオーバーフィッティング」記事の邦訳とみられる記録がある（書誌のみ、§4.7）。検証の落とし穴は [02_methodology_behavioral_japan_ml.md](02_methodology_behavioral_japan_ml.md) の A 節にまとめてある。
