> 要約: 2026-11-11 に国立国会図書館サーチ（NDLサーチ）の書誌を取得して照合した。従来の定番18点（国内発3点・海外名著の邦訳11点・日本人著者の入門書4点）のうち、LR-045 を除く17点で書名・著者（訳者）・出版者・刊行年を NDL の記載と照合し（✅P）、版元・年の誤りや欠落を訂正した。LR-045 は全集などの書誌までを確認した。
> §2.4 に海外名著の邦訳の確認表（NDL 記載の訳者・版元・刊行年・原タイトル）、§2.5 に日本語で書かれたチャート分析・ローソク足・一目均衡表・出来高・システムトレード・Python の専門書58点の書誌を置いた。確認したのは書誌の存在で、内容や品質の評価ではない。

## 1. 検証状況（先に結論）

- 確認日 2026-11-11。NDLサーチの OpenSearch（書誌レコードの API 応答）を取得し、書名・著者（訳者）・出版者・刊行年・ISBN を照合した。§2.1〜§2.3 の18行のうち、LR-045 を除く17行を ✅P とした。LR-045 は全集などの書誌までは確認したが、全集への所収関係が未確認のため、行の区分は ✅S のままとした。取得の方法と再現手順は [../08_primary_sources/02_ndl_cinii_jstage.md](../08_primary_sources/02_ndl_cinii_jstage.md) にある。
- 訂正した主な点: LR-043 の版元は日本経済新聞社で、2004.8 刊。LR-044 の版元は経済変動研究所で、NDL の著者標目は「一目山人」、蔵書は 1975.3〜1981.12 の6冊（「全七巻」は確認できず）。LR-052 の版元は金融財政事情研究会（きんざい）。LR-053 の版元は版により異なる。LR-113 の林康史は「編著」。詳細は 08 文書の訂正・追記ログ。
- §2.4 は海外名著の邦訳の確認表である。Bulkowski は NDL の応答が 429 で確認できず、Nison は NDL の創作者検索（原綴り）で英語原著2点と仏語訳1点しか見当たらず、書籍の邦訳を確認できなかった。ただし、題名「ローソク足」の検索応答には パンローリングの講義 DVD『スティーブ・ニソンの「ローソク足のツボ」』（2006、67分、ISBN 978-4-7759-6181-0） の記録がある[PB-007]（書籍ではなく、原綴りの創作者検索には現れなかった）。
- §2.5 は日本語の専門書58点を、書誌（書名・著者・出版者・刊行年・ISBN）が NDL に存在することだけ確認して分野別に並べた。**内容・品質の評価はしていない**。選定は題名・副題で分野が明確なものを編者が選んだもので、網羅ではない。
- 本文・目次は一冊も読んでいない。「内容の要点」は題名・副題・叢書名の中立的な言い換えである。
- 酒田五法・一目均衡表・出来高・システムトレード・Python の書名は §2.5 で確認した。需給分析の専門書は、題名に「需給」を含む検索が NDL の 429 で通らず、信用取引と出来高の書名にとどまる。選書の基準と書誌確認の手順は §3・§5 に残す。

## 4. 日本語のチャート分析書によくある品質上の問題

1. 後付けの事例だけで構成される。成功例が選ばれており、同条件で失敗した例が示されない。
2. 勝率だけを示し、ペイオフ比、期待値、母数、期間が示されない。
3. 指標の定義が曖昧で、移動平均線の種類やRSIの平滑化など実装差が書かれていない。
4. 手数料、税、スリッページ、約定の遅れが検証に含まれていない。
5. 刊行年が古く、取引時間・呼値・信用規制などの制度が現在と異なる。
6. 著者の運用実績が自己申告で、第三者による検証がない。教材・サロン・口座開設への誘導が併せてある場合は、利益相反も評価に入れる。
7. 一人の著者の手法が万能であるかのように書かれ、有効性が市場・時期で変わりうる点（適応的市場の考え方、LR-041）に触れない。

## 5. 書誌の確認手順

1. 国立国会図書館サーチで書名・著者を検索し、出版社・刊行年・版を記録する。英語版の記録が国内目録にあることは確認できた（LR-057、LR-058）。
2. 出版社の公式目録・書店の商品ページで、版（改訂・増補）、電子版、在庫の有無を照合する。
3. CiNii など別の目録で、2件以上が一致するまで確認する。邦訳は、原著の版との対応も確認する。
4. 不一致は捨てずに、出典表のメモに書き残す。確認できない項目は「未確認」とする。
5. NDL サーチの OpenSearch API（蔵書に限る `dpid=iss-ndl-opac`）で書名・著者・版元・年・ISBN・原タイトルを機械的に取得できる。手順と制限（429 の頻発など）は [../08_primary_sources/02_ndl_cinii_jstage.md](../08_primary_sources/02_ndl_cinii_jstage.md) にある。

## この文書の限界

- 書誌は NDL サーチの OpenSearch 応答（2026-11-11 取得）に基づく。書誌ページ（HTML）を取得して照合したのは LR-043 の1件だけである。書名・出版者・年・ISBN は NDL の記載で、実物（奥付）は見ていない。
- 本文・目次は読んでいない。§2.5 の「範囲」は題名・副題・叢書名の言い換えで、品質の評価ではない。難易度は編者の判断で、読了に基づくものではない。
- 資料は NDL の蔵書（`dpid=iss-ndl-opac`）に限られ、検索語ごとに上位100〜200件を見たものである。網羅ではなく、同題が版・刷ごとに別書誌で載る。
- NDL の応答が 429（同時アクセス制限）で得られなかったもの: Bulkowski の邦訳、『相場罫線術講義』（1904年）、`idx` によるページ送り、題名「需給」の検索。Nison の書籍の邦訳は NDL で確認できていない（講義 DVD の記録はある）。標目の表記ゆれによる漏れは排除できない。
- 一目山人と細田悟一の同一性、LR-045 の全集への所収関係は、NDL の取得項目では確認できていない。
- 邦訳が原著のどの版に対応するか（NDL 注記に版がないもの）、絶版かどうかは確認していない。
- 刊行年は NDL の「出版年」欄による。刷（第2刷など）と版の区別は NDL の記載のままである。
