# 学習ロードマップ（基礎→実践→検証→自動化）
> 要約: テクニカル分析を「定義→計算→売買ルール→検証→自動化」の4段階で学ぶ道筋を、読む資料（本リポジトリの文書と書籍）、実習、到達チェックリストの形で示した。
> 中核の考え方は、手法を信じる前に規則化して検証することである。研究では有効性の評価が割れ、検定の不備も指摘されている[LR-098]。
> 期間の目安は編者の判断で、根拠となる研究はない。書籍IDは 01_books_english.md と 02_books_japanese.md、論文IDは本ファイルの出典表を参照。
> 最終更新: 2026-11-11

## 1. 全体像

| 段階 | 到達目標 | 期間の目安 | 主な成果物 | 次へ進む条件 |
|---|---|---|---|---|
| ① 基礎 | 価格・出来高・基本指標を、定義と計算式で説明できる | 4〜6週 | 指標の再計算シート、トレンド区間のルール化メモ | 指標の値をチャートツールと一致させられる |
| ② 実践 | 売買ルールを1枚の仕様書にし、記録をつけて回せる | 8〜12週 | 売買仕様書、チャート日誌 | 仕様どおりに実行し、違反を数えられる |
| ③ 検証 | ルールが偶然でないかを、コスト込みで評価できる | 8〜12週 | バックテスト報告、頑健性の確認表 | 検証用データを触らずに結論を出せる |
| ④ 自動化 | データ取得から報告までを再現可能にする | 継続 | 再現可能なパイプライン | 実装の値が参照実装と一致し、停止基準がある |

基本方針:

1. 学ぶことと信じることを分ける。実務家の利用は広いが（ファンドマネージャー692人の調査で大多数が利用し、数週間先の予測では最重要の分析手法とされた[LR-099]）、収益性の研究結果は割れている[LR-098]。
2. 規則化できないものは検証できない。パターン名は数値の判定規則に落とす。
3. 日本株の制度と実務（値幅制限、呼値、単元株、権利落ち、信用規制）を最初から併せて学ぶ。
4. 最短で時間がない場合: 入門書 LR-005 → 検証書 LR-028 → 批判的視点 LR-037。文書は ../01_techniques/01_price_structure.md → ../03_evidence/02_methodology_behavioral_japan_ml.md → ../05_tools_data_code/05_backtesting_frameworks.md の順。

## 2. 段階別の道筋

### 2.1 ① 基礎

目標: ローソク足、出来高、トレンド、支持線（サポート）・抵抗線（レジスタンス）、主要指標を「定義→計算→読み方→限界」で説明できる。

読む順（本リポジトリ）:

1. [../01_techniques/01_price_structure.md](../01_techniques/01_price_structure.md): ダウ理論・トレンド・支持抵抗・ギャップ
2. [../01_techniques/03_candlesticks.md](../01_techniques/03_candlesticks.md) と [../02_japan/01_sakata_gohou.md](../02_japan/01_sakata_gohou.md): ローソク足と酒田五法
3. [../01_techniques/06_moving_averages.md](../01_techniques/06_moving_averages.md) → [07_oscillators_momentum.md](../01_techniques/07_oscillators_momentum.md) → [08_volatility_and_trend_strength.md](../01_techniques/08_volatility_and_trend_strength.md) → [09_volume_breadth_sentiment.md](../01_techniques/09_volume_breadth_sentiment.md)
4. [../02_japan/04_tse_market_rules_and_chart_effects.md](../02_japan/04_tse_market_rules_and_chart_effects.md): 東証の制度がチャートに与える影響

書籍: 入門 LR-005 または LR-001、定義の辞典 LR-015、ローソク足 LR-009。邦訳は 02_books_japanese.md（LR-046 など。国立国会図書館の書誌で確認済み）。用語固定には 03_online_courses_and_sites.md の用語集。

実習:

- 20銘柄の日足を選び、トレンド区間（上昇・下降・レンジ）を手作業でラベル付けする。次に、反転幅の閾値（例: 直近の極値からATR（平均真の値幅, average true range）のk倍の逆行）を決めて機械的に判定し、一致率を見る。閾値の決め方は ../01_techniques/ の各文書を参照。
- SMA、EMA、RSI、MACD、ボリンジャーバンドをスプレッドシートで再計算し、チャートツールの値と一致させる。代表的な設定は RSI 14、MACD 12・26・9、ボリンジャー 20・±2σ だが、出典と差異（RSIの平滑化、標準偏差の定義）は 06〜08 の各文書で確認する。一致しない場合の原因の多くは平滑化方式と初期値の違いである。
- 同じ銘柄の調整後株価と未調整株価で移動平均線を計算し、分割・配当のある時点での差を確認する。

到達チェックリスト:

- [ ] 高値・安値の切り上げ（下げ）で上昇（下降）トレンドを判定する規則を、数値で書ける
- [ ] 支持線・抵抗線の引き方を、再現可能な手順で説明できる
- [ ] ローソク足の主要パターン3つ以上を、実体・影の比率で定義できる
- [ ] RSI・MACD・ボリンジャーバンドを、チャートツールと一致する値で再計算できる
- [ ] 出来高が価格の動きを裏づけるかを、判定基準つきで説明できる
- [ ] 値幅制限、呼値、権利落ちがチャートにどう現れるかを日本株の例で示せる
- [ ] 各指標の限界（遅れ、レンジ相場での騙し）を1つ以上言える

### 2.2 ② 実践

目標: エントリー、損切り、利益確定（またはトレーリング）、ポジションサイズ、見送り条件を1枚の仕様書にし、記録をつけて実行する。

読む順:

1. [../01_techniques/02_chart_patterns.md](../01_techniques/02_chart_patterns.md)、[10_alt_charts_relative_strength_mtf.md](../01_techniques/10_alt_charts_relative_strength_mtf.md)、[05_practitioner_frameworks.md](../01_techniques/05_practitioner_frameworks.md)
2. 日本固有: [../02_japan/02_ichimoku_kinko_hyo.md](../02_japan/02_ichimoku_kinko_hyo.md)、[03_other_japanese_methods.md](../02_japan/03_other_japanese_methods.md)、[05_supply_demand_indicators.md](../02_japan/05_supply_demand_indicators.md)

書籍: パターン LR-008、個別株の枠組み LR-022・LR-024・LR-025（成績は自己申告なので手法の根拠にしない）、資金管理と心理 LR-027・LR-042。波動・出来高系（LR-016〜LR-020）は、主観が入りやすい点を踏まえて読む。日本固有の古典・原典は LR-044・LR-045（02_books_japanese.md）。

実習:

- 仕様書は [../06_workflow/02_checklists_and_templates.md](../06_workflow/02_checklists_and_templates.md) の B（ルール仕様書）の全欄を埋める。そのうえで、対象銘柄の条件（売買代金、貸借銘柄かどうか）、損切り位置（価格・ATR・構造）、1回の許容損失（資金の一定割合）、見送り条件（決算前後など）を自分の手法に合わせて具体化する。
- 日本株の例外処理: ストップ安・ストップ高の張り付きで損切り注文が約定しない場合、寄り付きのギャップで損切り価格を飛び越える場合を、仕様に書く。
- 記録は同ファイルの E（取引日誌の列定義）で残す。期待値の指標は R倍数（R-multiple。損益を想定リスクで割った値）で統一し、仕様どおりに実行したか（followed_plan）も記録する。分析メモは A の雛形を使う。
- 標本数の感覚: 勝率の標準誤差は sqrt(p(1-p)/n) である。p=0.5 のとき、n=30 で約9ポイント、n=100 で約5ポイント、n=400 で約2.5ポイントになる。数回の連勝・連敗で手法を評価しない。

到達チェックリスト:

- [ ] 仕様書の全項目が埋まり、第三者が同じ判断を再現できる
- [ ] 1回の許容損失とポジションサイズの計算式を持っている
- [ ] 取引ごとに、仕様に従ったか（違反の有無）を記録している
- [ ] 期待値（平均R）、勝率、ペイオフ比、最大の連敗数を集計できる
- [ ] 損切りの未約定（ストップ高安・ギャップ）への対応を決めている
- [ ] 自分の手法の弱い局面（例: レンジ、急落）を、記録から1つ以上特定した

### 2.3 ③ 検証

目標: ルールが偶然の産物でないかを、コスト込み・期間分割・頑健性確認で評価する。

読む順:

1. [../03_evidence/01_academic_literature.md](../03_evidence/01_academic_literature.md) と [02_methodology_behavioral_japan_ml.md](../03_evidence/02_methodology_behavioral_japan_ml.md)
2. [../05_tools_data_code/05_backtesting_frameworks.md](../05_tools_data_code/05_backtesting_frameworks.md)、データは [02_data_sources.md](../05_tools_data_code/02_data_sources.md)
3. [../06_workflow/02_checklists_and_templates.md](../06_workflow/02_checklists_and_templates.md) の C（先読み・データ・生存者バイアス・コストの設計チェックリスト）と、[../06_workflow/01_analysis_procedure.md](../06_workflow/01_analysis_procedure.md) の 7（検証手順の概要）

書籍・論文: LR-028（客観的ルールの評価とデータマイニング・バイアス）→ LR-029（ウォークフォワード）→ LR-030・LR-034（網羅）→ LR-036・LR-039（批判的視点）。論文は、Park & Irwin（レビュー）[LR-098]、Menkhoff（実務家の利用）[LR-099]、Bessembinder & Chan（コスト）[LR-100]、Marshall ほか（データスヌーピング）[LR-101]。

論文から言えること（要点のみ）:

- Park & Irwin の2007年版レビューは、検定手法が改善された後の「近年型（modern）」研究95件のうち、肯定56・否定20・混合19と集計する。一方で、データスヌーピング（data snooping）、規則の事後選択、リスクとコストの推定の難しさなど、検定上の問題が多いと指摘する。2004年のワーキングペーパー版は92研究（肯定58・否定24・混合10）で、集計は版により異なる[LR-098]。
- Bessembinder & Chan は、単純なテクニカル規則に統計的な予測力はあるが、リターンは取引コストを上回るほど大きくないとする[LR-100]。
- Marshall ほかは、米国株の日中データで7,846個の規則を検証し、データスヌーピング補正後は収益性のある規則がなかったと報告する[LR-101]。
- いずれも対象市場と期間が限られる。日本株の結果は ../03_evidence/02_methodology_behavioral_japan_ml.md を参照。

検証の手順（推奨）:

1. ルールを事前に1文で固定し、試す規則とパラメータの数を記録する（多重検定の補正に使う）。独立な無効ルールを20個試すと、5%水準で少なくとも1つが偶然有意になる確率は 1−0.95^20 で約64%、100個なら約99%である。
2. データを学習／検証／最終ホールドアウト（hold-out）に分ける。最終ホールドアウトは1回だけ使う。
3. コスト（手数料、スプレッド、スリッページ、税）を入れ、コストを倍にしたときの感応度も見る。
4. ルックアヘッド（look-ahead）を排除する。当日の終値で判定したシグナルを当日の終値で約定したことにしない。約定の仮定（翌日始値など）を明記する。
5. 生存者バイアス（survivorship bias）を避ける。上場廃止銘柄を含むデータで検証し、指数構成の入れ替えも考慮する。
6. パラメータの近傍で成績が安定するか（尖った山でなく台地か）を見る。ウォークフォワード（walk-forward）[LR-029]で再最適化の影響も見る。
7. ランダムなエントリーや単純保有との比較、銘柄・期間・市場を変えた頑健性の確認を行う。
8. 指標は、年率リターン、最大ドローダウン（maximum drawdown）、取引回数、勝率とペイオフ比（payoff ratio）、期待値（R）、回転率（コスト感応度）を併記する。シャープレシオは、年率換算と無リスク金利の仮定を明記する。

到達チェックリスト:

- [ ] 試した規則とパラメータの総数を記録し、多重検定の影響を説明できる
- [ ] 学習／検証／最終ホールドアウトを分け、最終用を1回しか使っていない
- [ ] コストと約定の仮定を明記し、コスト倍の感応度を確認した
- [ ] 上場廃止銘柄とルックアヘッドの扱いを説明できる
- [ ] 成績が、別の銘柄群または別の期間でも崩れないかを確認した
- [ ] 結論を「有効」「無効」でなく、条件つきの確度として書ける

### 2.4 ④ 自動化

目標: データ取得→前処理→シグナル→バックテスト→報告を、再現可能な1つの手順にする。

読む順: [../05_tools_data_code/02_data_sources.md](../05_tools_data_code/02_data_sources.md) → [03_python_libraries.md](../05_tools_data_code/03_python_libraries.md) → [04_javascript_and_other_libraries.md](../05_tools_data_code/04_javascript_and_other_libraries.md) → [05_backtesting_frameworks.md](../05_tools_data_code/05_backtesting_frameworks.md)。参考実装は [../07_reference_code/README.md](../07_reference_code/README.md)（指標・ローソク足・スイングの実装、TA-Lib との数値照合、先読み検査のテスト）、手順書は [../06_workflow/01_analysis_procedure.md](../06_workflow/01_analysis_procedure.md)。

書籍: 実装 LR-031・LR-033、金融データの機械学習 LR-032、ルール設計 LR-034、株式モメンタム LR-026・LR-035。

実習:

- 指標の自前実装を、参考実装（TA-Lib との照合テストを含む）の値と比較し、許容誤差を決める。
- 乱数シード、データの取得日と版、パラメータを設定ファイルに残し、同じ結果が再現できることを確認する。
- 実運用前の段階を置く: 過去検証→ペーパートレード→少額→通常。各段階の移行基準と停止基準（期待分布を超える連敗やドローダウン）を事前に書く[LR-033]。
- 発注の自動化の前に、通知のみの段階を置く。

到達チェックリスト:

- [ ] 1コマンドでデータ取得から報告まで再現でき、結果が一致する
- [ ] 指標の実装が参照実装と許容誤差内で一致する
- [ ] データの出所、取得日、調整方法が記録されている
- [ ] 戦略の停止基準と、実運用での乖離の検知方法が文書化されている
- [ ] ライブラリのバージョンを固定し、更新時に再テストする手順がある

## 4. やってはいけない学び方

| やってはいけないこと | 理由 | 代わりに |
|---|---|---|
| 成功例のチャート画像だけで学ぶ | 後知恵と生存者バイアスで、見えるのは勝ったケースだけ（LR-039） | 同じ定義で機械的に全件を抽出し、失敗例も含めて統計を取る |
| パターン名の暗記で実戦に入る | 定義が曖昧だと検証できず、成功率は定義に依存する（LR-008） | 数値の判定規則に落とす |
| 指標を重ねて「一致したら強い」と考える | 同系統の指標は同じ価格情報の変換で、独立した確認にならない | 系統（トレンド／モメンタム／ボラティリティ／出来高）ごとに1つ選ぶ |
| 同じデータで探索と評価を兼ねる | 試行数が増えるほど偶然の好成績が選ばれる（20回で約64%） | 期間分割、最終ホールドアウト、ウォークフォワード |
| コストを無視して検証する | 売買が多い手法ほど利益が消え、単純規則の予測力もコストに負けるとの報告がある[LR-100] | 手数料・スプレッド・スリッページ・税を入れ、倍にして感応度を見る |
| 現存銘柄だけで検証する | 上場廃止の除外は生存者バイアスになる | 上場廃止銘柄を含むデータを使う |
| 勝率だけで評価する | 勝率が高くても平均損失が大きければ期待値は負になる | 期待値（R）、ペイオフ比、最大ドローダウンを併記する |
| 成績自慢や販売教材を根拠にする | 自己申告の実績や出版社の紹介文は検証資料ではない（LR-023） | 規則と検証データが開示された資料を優先する |
| 損切りとポジションサイズなしで実弾を入れる | 手法の優位性より先に、資金が尽きる確率が支配する | 1回の許容損失を資金の一定割合に固定する |
| 少数の連勝・連敗で手法を変える／信じる | 標本が小さいと勝率の推定誤差は大きい（30回で約9ポイント） | 事前に決めた回数と基準で評価する |
| 「無効」「必ず有効」のどちらかに決めつける | 研究は割れ、有効性は市場・時期で変わりうる（LR-041）[LR-098] | 自分の市場・時間軸・コストで検証し、確度を条件つきで書く |
| 個人発信の再生数やフォロワー数を信頼の根拠にする | 品質が不均一で、教材販売・口座開設への誘導という利益相反がある | 運営主体、出典、検証データの有無で評価する（03_online_courses_and_sites.md） |
| 英語圏の手法を日本株へそのまま使う | 値幅制限、呼値、単元株、取引時間、信用規制が異なる | ../02_japan/04_tse_market_rules_and_chart_effects.md で制度差を確認する |

## 5. 記録とテンプレート

雛形は [../06_workflow/02_checklists_and_templates.md](../06_workflow/02_checklists_and_templates.md) にある。段階ごとの使い分けは次のとおり。

| 段階 | 使う雛形 | 目的 |
|---|---|---|
| ② | A 分析メモ、B ルール仕様書、E 取引日誌 | 判断の根拠と仕様違反を残す。当時のチャート画像を保存し、後知恵を防ぐ |

検証ログ（バックテストごと）には、対象（銘柄群、期間、データの出所と取得日、調整方法）、設定（ルール、パラメータ、約定の仮定、コスト、試した規則数）、結果（年率リターン、最大ドローダウン、取引回数、勝率、ペイオフ比、期待値R、コスト倍の結果）、再現情報（実行コマンド、コードの版、ライブラリのバージョン、乱数シード）を残す。
