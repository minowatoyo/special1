## 3. 新値足（しんねあし, 3本新値足／Three-line break）

- 検証状況: 作図規則＝既存知識（⚠M）。Pythonパッケージに「Line Break」チャートの実装があることのみ確認 [JP1-064]。
- 定義: 時間の経過ではなく価格の更新だけで線を足す終値チャート。N本新値足（標準は3本）では、終値が直前線の高値（安値）を更新したときに同方向へ線を足し、逆方向へは「直近N本の最安値（最高値）を終値が抜いた」ときだけ反転線を足す。
- 作図規則（終値基準、N=3）: 直前が陽線なら、終値＞直前線の高値で陽線を追加（始点＝直前線の高値、終点＝新終値）。終値＜直近3本の最安値で陰線を追加して陰転（始点＝直前線の高値）。どちらでもなければ何も描かない。直前が陰線なら対称。
- 見方: 反転線は直近3本をまとめて包む大きな足になり、トレンド転換のフィルターとして使う。同色の線が続く間はトレンド継続とみる。
- 実装差（差が出うる点）: 終値基準か高値・安値基準か、本数N（2〜5など）、初期線の作り方、反転線の始点。
- 限界: 反転の確認が遅く、転換後に大きく逆行してから線が出る。レンジでは陽転・陰転が連発する。時間と出来高の情報がなく、開始位置により作図が変わる（経路依存）。

```python
def line_break(closes, n=3):
    L = []                                       # (lo, hi, dir): dir=+1 陽線 / -1 陰線
    for p, c in zip(closes, closes[1:]):
        if not L:
            if c != p: L.append((min(p, c), max(p, c), 1 if c > p else -1))
            continue
        lo, hi, d = L[-1]; ref = L[-n:]
        if d > 0:
            if c > hi: L.append((hi, c, 1))
            elif c < min(x[0] for x in ref): L.append((c, hi, -1))   # 陰転
        else:
            if c < lo: L.append((c, lo, -1))
            elif c > max(x[1] for x in ref): L.append((lo, c, 1))    # 陽転
    return L
```

## 4. カギ足（Kagi）

- 検証状況: すべて既存知識（⚠M）。Nison (1994) の副題が日本のチャート手法であることのみ確認 [JP1-018]。
- 定義: 日本発とされる、価格の方向転換だけで線を折り返すチャート。一定の転換幅（固定値・%・ATRなど）以上の逆行でのみ向きを変える。
- 作図規則: 上昇中に転換幅以上下げると下向きに折り返す（下降は対称）。直前の高値（肩）を超えると太線（陽線）、直前の安値（腰）を割ると細線（陰線）に切り替える。横軸は等間隔の時間ではない。
- 見方: 太線への転換は需給の改善、細線への転換は悪化とみる。太線が続く間は上昇基調。
- 実装差: 転換幅の決め方、終値基準か高値・安値基準か、肩・腰の定義。
- 限界: 転換幅が恣意的（小さいと線が増え、大きいと遅れる）。時間・出来高を失う。詳細は [代替チャート](../01_techniques/10_alt_charts_relative_strength_mtf.md) を参照。

## 5. 大循環分析

- 検証状況: 6通りの並びとその循環＝論理的に導出（確実）。EMA期間（5・20・40）とステージの呼称・解釈＝既存知識で未検証。考案者・初出は未確認。
- 定義: 短期・中期・長期の3本の移動平均線の上下関係は6通りで、価格の変動に伴い1→2→…→6→1と一方向に循環する。並びをステージとして相場局面を分類する。一般に指数移動平均の5・20・40が使われると紹介される（⚠M、要確認）。

| ステージ | 並び（上→下） | 一般的な説明（⚠M） | 前ステージからの変化 |
|---|---|---|---|
| 1 | 短＞中＞長 | 安定上昇（上昇パーフェクトオーダー相当） | 中期が長期を上抜け |
| 2 | 中＞短＞長 | 上昇の終盤・下落の初動 | 短期が中期を下抜け |
| 3 | 中＞長＞短 | 下落局面入り | 短期が長期を下抜け |
| 4 | 長＞中＞短 | 安定下降 | 中期が長期を下抜け |
| 5 | 長＞短＞中 | 下降の終盤 | 短期が中期を上抜け |
| 6 | 短＞長＞中 | 上昇の初動 | 短期が長期を上抜け |

- 大循環MACD: 3本の差（短期−中期、短期−長期、中期−長期）をMACDとして並べたもの。ゼロ線との交差が移動平均線の交差に対応する。3つの符号の組は8通りのうち矛盾する2通りを除く6通りで、ステージに一致する。シグナル線の使い方は流派による（⚠M）。
- 見方: ステージ1・4は順張り、2・3・5・6は転換への警戒、と整理されることが多い。売買ルールの標準形は未確認。
- 実装差: SMAかEMAか、期間、ステージ番号の付け方（番号の割り当ては流派で異なりうる）。
- 限界: 並びが確定してから動くトレンド確認型で遅い。レンジでは2・3・5・6を行き来し、ステージが頻繁に入れ替わる。

## 6. パーフェクトオーダーと日本の標準的な移動平均設定

- 検証状況: 定義と標準期間＝既存知識（⚠M）。標準期間は日本のチャートソフトの既定値として広く使われるが、各社の既定は未確認（要公式確認）。
- 定義: 短期＞中期＞長期の順で、かつ3本とも上向きの状態を上昇パーフェクトオーダー、逆を下降とする。大循環分析のステージ1・4に「全線の傾き」の条件を加えたものに当たる。
- 標準期間: 日足は5・25・75日（約1週・1か月・3か月）、週足は13・26・52週（四半期・半期・1年。日足換算で約65・130・260日）。200日線を加える変形もある。
- 見方: トレンドの強さの確認、短期線付近への押し目の買い場の判断、短期線が中期線を割れば一服のサイン。スクリーニングの定番条件でもある。
- 実装差: SMAかEMAか、「上向き」の定義（前日比、N日前比、回帰傾き）、成立日の数え方。週足のMAは週足終値の平均で、日足65日線とは祝日・欠け週で厳密には一致しない。
- 限界: 成立時点で既に大きく上昇済みのことが多く、レンジでは頻繁に崩れる。
- 参考: 移動平均線全般とグランビルの法則は [移動平均線](../01_techniques/06_moving_averages.md)。

```
po_up = (ma5 > ma25) & (ma25 > ma75) & (ma5 > ma5.shift(1)) & (ma25 > ma25.shift(1)) & (ma75 > ma75.shift(1))
```

## 7. 移動平均乖離率

- 検証状況: 式＝定義上確実。しきい値＝未検証。
- 計算式: `乖離率(%) = (終値 - n日移動平均) / n日移動平均 × 100`。日本では25日（約1か月）が基準として好まれる（⚠M）。
- 見方: 正に大きいほど買われ過ぎ、負に大きいほど売られ過ぎとみる逆張り指標。日本の解説では、日経平均のような指数で±5〜10%程度、個別株でそれ以上（±10〜20%超など）を行き過ぎの目安とする例が多いが、数値は解説ごとに異なり、本調査では根拠を確認できていない（未検証）。
- 実装上の勧め: 固定％でなく、銘柄ごとの過去分布の分位点（例: 5%・95%）や、乖離率を過去σで標準化した値でしきい値を決める。ボラティリティの大きい銘柄ほど同じ乖離率の意味が軽い。
- 限界: 強いトレンドでは乖離が拡大し続け、逆張りが失敗する。平均回帰が働くレンジ局面でしか使えず、期間の選び方で結果が変わる。
- 実装差: 移動平均がSMAかEMAか、基準期間、乖離率を終値でなく高値・安値で測る流儀の有無（未確認）。

## 8. サイコロジカルライン

- 検証状況: 式と既定の12日＝確認 [JP1-052]。売買の目安（75%・25%）＝既存知識で未検証。
- 計算式: `PSL(%) = 過去N日のうち前日比上昇の日数 / N × 100`。標準はN=12 [JP1-052]。
- 見方: 日本の解説では、75%以上（12日中9日以上）で買われ過ぎ、25%以下（3日以下）で売られ過ぎとみる逆張り指標として紹介される（⚠M・未検証）。
- 統計的な注意: 上昇日の確率を0.5で独立と仮定すると、12日中9日以上上昇する確率は299/4096＝約7.3%、10日以上は79/4096＝約1.9%（二項分布の計算値）。実際の株式は上昇日の確率が0.5ではなく系列相関もあるため、サインは理論より頻発し、トレンド相場では張り付く。
- 実装差: 「変わらず」の日の扱い（上昇に含めない／0.5日とする）、N、前日比か陽線本数か（後者の流儀の有無は未確認）。
- 限界: 上昇幅を無視し、1日の大きな下落と小さな下落を同じに扱う。学術では投資家心理の代理変数に使った例がある（ベトナム、要旨のみ）[JP1-073]。

## 9. 騰落レシオ（25日）

- 検証状況: 式＝既存知識（⚠M）。120%・70%の目安＝未検証。対象母集団の仕様は提供元ごとに要確認。
- 計算式: `騰落レシオ(%) = (25日間の値上がり銘柄数の合計) / (25日間の値下がり銘柄数の合計) × 100`。対象は東証の全銘柄（旧東証一部、2022年の市場区分見直し後はプライムなど）が一般的とされるが、提供元により異なりうる。
- 見方: 100%が均衡。120%以上で過熱、70〜80%以下で売られ過ぎ、とする目安が日本で広く紹介される（⚠M・未検証）。市場全体の需給の温度計として、指数との乖離を見る使い方もある。
- 実装差: 対象市場、期間（6日・10日・15日・25日など）、「変わらず」銘柄の扱い（通常は除外）、25日の合計か日次比率の平均か。
- 限界: 母集団の変化（新規上場・上場廃止・市場区分）、値動きの大きさを無視、小型株に引きずられた指数との乖離。120%超が長く続く局面もあり、しきい値は時代で変わる。関連指標は [出来高・騰落・センチメント](../01_techniques/09_volume_breadth_sentiment.md)。

## 11. ボリンジャーバンドの日本での使われ方

- 検証状況: 欧米の既定値＝確認 [JP1-052]。日本の慣行＝既存知識で未検証。
- 計算式: `中心線 = n日SMA、上下 = 中心線 ± k × σ`。欧米の実装の既定は20日・2σ [JP1-052]。日本の解説・チャートでは25日が好まれ、±1σ・±2σ・±3σを重ねて表示する例が多い（⚠M）。
- 日本での使われ方: 順張りの「バンドウォーク」（±2σ沿いに推移して強いトレンド継続を示す）、バンド幅の縮小（スクイーズ）と拡大（エクスパンション）による値動きの変化、±2σタッチでの逆張り、の3系統が解説される（⚠M）。
- 統計的な注意: 正規分布なら±1σ・±2σ・±3σに収まる確率は約68.3%・95.4%・99.7%（理論値）。実際の株価は裾が厚く系列相関もあるため、±2σ外が連続するバンドウォークが起きる。
- 実装差: σが母標準偏差か標本標準偏差か（ライブラリで異なる）、期間・倍率の既定値（ツールごと）。
- 限界・エビデンス: 米国の長期データで、下側バンド割れの買いシグナルが買い持ちを上回ったとする報告があるが、要旨のみで条件依存 [JP1-072]。詳細は [ボリンジャー等](../01_techniques/08_volatility_and_trend_strength.md)。

| 掉尾の一振・夏枯れ・ニッパチ | 年末の上昇、夏の閑散、2月・8月の弱さ | 未検証（名称のみ） |

- 干支の証拠: 株式ファクター（市場・規模・バリュー・モメンタム）を1927〜2015年の干支別に比べても、平均リターンが干支間で等しいという帰無仮説は棄却されず、干支に基づく戦略が優位性を生む可能性は低いと結論 [JP1-070]。ハンセン指数は子年に高く巳年に低い一方、S&P500では巳年・酉年のみ低く、その他は結論が出ないとの報告もある [JP1-071]。
- 標本の小ささ: 戦後約75年のデータでは各干支は6回強しかなく、12区分から事後的に目立つ年を拾えば偶然でも「当たる」。1989年末（巳年）のバブル天井のような象徴的事例は選択バイアスを疑う。
- 民間伝承として扱い、運用判断の根拠にしない。季節性を使うなら [検証手法の落とし穴](../03_evidence/02_methodology_behavioral_japan_ml.md) の多重検定・サンプル外検証を適用する。
