# チャート分析の実践手順（トップダウンと、検証できるルールへの落とし込み）
> 要約: 市場環境 → セクター → 個別銘柄 → シナリオ化 → リスク管理 → 記録、の6段階で進める手順書。チャート分析を「未来の予言」ではなく「どこで入り、どこで間違いと認め、いくら賭けるかを事前に決める枠組み」として使う。各段階で参照すべき本資料集の文書を示す。学術的なエビデンスは限定的・対立的であり（`../03_evidence/`）、本手順は手法の有効性を前提にしない。
> 最終更新: 2026-11-09

## 0. この手順の位置づけ

- **目的**: 判断を再現可能にすること。同じ画面を見て毎回違う結論を出さないために、見る順番と記録の型を固定する。
- **やらないこと**: 売買の推奨、将来の値動きの断定。以下の数値例はすべて説明用で、推奨値ではない。
- **エビデンスとの付き合い方**:
  - 裁量でチャートを読む行為の有効性は、学術研究では弱い・対立的な結果が多い。機械的に定義できるルール（移動平均、ブレイクアウト、モメンタム等）の方が検証しやすく、一部の市場・期間で支持する結果もあるが、取引コスト・データスヌーピング・期間依存に弱い（`../03_evidence/01_academic_literature.md`、`../03_evidence/02_methodology_behavioral_japan_ml.md`）。
  - したがって「パターン＝仮説」と扱い、(a) 無効化条件を先に決める、(b) 可能なら機械的に定義して検証する、(c) 結果が弱ければ捨てる、を原則とする。

## 2. 各段階の進め方

### 段階0: 目的・時間軸・許容損失

- 時間軸（数日のスイング／数週間〜数か月／長期）を先に決める。チャートの足は保有期間の数分の1〜数倍を目安に選ぶ（スイングなら日足を主、週足を上位足）。
- 1回の取引で許容する損失額（口座資金に対する割合）を決める。これが段階5のポジションサイズの出発点になる。

### 段階1: 市場環境（指数・ボラティリティ・需給）

見るもの:
- 日経平均・TOPIX の**週足 → 日足**で、トレンドの向き（高値・安値の切り上げ/切り下げ）と主要な移動平均線との位置関係。
- ボラティリティ（日経VIなど）と指数の値幅（ATR）。値動きが荒い局面では、同じ損切り幅でも逆行に巻き込まれやすい。
- 需給: 信用買い残・信用倍率、投資部門別売買状況（海外投資家・個人の売買）、空売り比率など（意味と限界は [需給指標](../02_japan/05_supply_demand_indicators.md)）。
- イベント: SQ週、決算シーズン、日銀・FOMC など。**イベントの日付は個別に確認**する（本資料集は日付を保証しない）。

よくある誤り: 個別銘柄だけを見て相場全体の向きを無視する／需給指標を単独の売買シグナルとして使う。

### 段階2: セクター・相対力

- 業種別指数や代表銘柄で、指数に対する相対力が上向いているセクターを探す。相対力は「指数に対する比」の推移で見る（RSライン、RRG）。
- 個別銘柄の相対力ラインが高値更新しているか、セクターと指数のどちらに連動しているかを確認する。

よくある誤り: 相対力が強い＝これから上がる、と読む（過去に強かったことを示すだけで、持続は検証事項）。

### 段階3: 個別銘柄の構造（上位足から下位足へ）

**3-1 データの確認（最初に必ず）**
- 株式分割・併合・権利落ちの調整が済んだ価格か（ベンダごとに調整の流儀が違う。[東証の制度とチャート](../02_japan/04_tse_market_rules_and_chart_effects.md)）。
- 流動性: 売買代金と出来高。板が薄い銘柄はスリッページが大きく、損切り注文が想定価格で約定しない。
- 予定されたイベント: 決算発表日、権利付き最終日、増資・転換社債などの材料。決算をまたぐとギャップ（窓）で損切りを飛び越える可能性がある。
- 値幅制限・呼値の単位: 値幅制限に張り付くと約定できない日がある。呼値の刻みは低位株ほど価格に対して粗く、サポート・レジスタンスの精度を下げる。

**3-2 トレンドと水準（月足 → 週足 → 日足）**
- トレンドの向きを高値・安値の切り上げ/切り下げで定義する（[価格構造](../01_techniques/01_price_structure.md)）。主観を減らすなら、ジグザグやフラクタルで機械的に定義し、確定足以降にのみ使う（[参考実装](../07_reference_code/README.md)）。
- 水準: 前回の高値・安値、レンジの上下端、キリの良い価格、出来高が集中した価格帯。複数の根拠が重なる水準ほど意識されやすい、という仮説で扱う。
- 移動平均線: 日本では 5・25・75日などが慣行として広く使われる（[移動平均](../01_techniques/06_moving_averages.md)）。傾きと、価格・各線の並び（パーフェクトオーダー等）を状態として記述する。

**3-3 パターンと足の形**
- チャートパターンやローソク足は、形成条件・確認条件（終値での突破、出来高の増加など）・無効化条件をセットで記述する（[パターン](../01_techniques/02_chart_patterns.md)、[ローソク足](../01_techniques/03_candlesticks.md)）。形が「それらしい」だけでは根拠にしない。
- 「ダマシ」は例外ではなく通常の結果の一部。確認条件を厳しくすると機会が減る代わりに誤信号も減る、というトレードオフとして扱う。

**3-4 モメンタムとボラティリティ（補助）**
- RSI・MACD・ストキャスティクスなどは、トレンドの強弱・過熱・ダイバージェンスの**補助情報**。強いトレンドでは「買われすぎ」のまま張り付くので、逆張りの根拠にしない（[オシレーター](../01_techniques/07_oscillators_momentum.md)）。
- ボリンジャーバンド・ATR は、値幅の大きさとレンジ拡大/収縮の把握、損切り幅の設計に使う（[ボラティリティ](../01_techniques/08_volatility_and_trend_strength.md)）。

**3-5 出来高**
- ブレイクアウト時の出来高増加、クライマックス（急騰・急落での出来高急増）、枯れ（出来高の減少）を確認する（[出来高](../01_techniques/09_volume_breadth_sentiment.md)）。出来高の水準は銘柄ごとに違うので、自身の過去平均との比で見る。

**3-6 需給（日本株）**
- 信用買い残が積み上がった銘柄は、株価が戻る局面で売り圧力（やれやれ売り・期日到来）になりやすい、という仮説がある。有効性は銘柄と局面に依存し、単独のシグナルとしては扱わない（[需給指標](../02_japan/05_supply_demand_indicators.md)）。

### 段階4: シナリオ化（条件と無効化を先に書く）

次の形で、エントリー前に書き出す（テンプレートは [チェックリスト](02_checklists_and_templates.md)）。

| 項目 | 例（説明用） |
|---|---|
| 仮説 | 週足は上昇トレンド。日足で25日線までの押し目から再上昇する |
| トリガー | 日足終値が直近の戻り高値を上抜け、当日出来高が20日平均を上回る |
| 無効化（損切り） | 押し安値を終値で割り込む |
| 目標・出口 | 前回高値、または トレーリング（ATRの一定倍・直近安値の切り上げ） |
| 見送り条件 | 決算発表が3営業日以内／売買代金が基準未満／指数が急落中 |

重要なのは、**無効化条件を「入る前に」書く**こと。入ってから損切り位置を動かすと、チャート分析が後付けの正当化に変わる。

### 段階5: リスク管理（損切りとポジションサイズ）

- **損切り位置**は、(a) 構造（直近の押し安値の少し下）か (b) ボラティリティ（エントリー − k × ATR）で決める。k の値に普遍的な正解はなく、銘柄のボラティリティと保有期間に合わせて検証で決める。
- **ポジションサイズ**（1回の許容損失から逆算）:

```
株数 = 切り捨て( 口座資金 × 許容損失率 ÷ (エントリー価格 − 損切り価格) ÷ 売買単位 ) × 売買単位
例: 口座 1,000万円、許容損失率 0.5%（= 5万円）、エントリー 2,000円、損切り 1,900円
    → 5万円 ÷ 100円 = 500株 → 売買単位100株で割り切れるので 500株
```
- 注意: ギャップ・値幅制限・流動性不足では、損切り注文が想定価格で約定せず**実際の損失は想定を超えうる**。手数料・スプレッド・信用の金利や貸株料はこの式に入っていない。

### 段階6: 記録と検証

- 取引日誌に、分析時点のチャート画像、シナリオ票、結果を残す（[テンプレート](02_checklists_and_templates.md)）。
- 手法を自分のルールとして使い続けるなら、(a) 機械的に定義し (b) 過去データで検証し (c) 実際の成績と比べる。検証の落とし穴は [検証手法](../03_evidence/02_methodology_behavioral_japan_ml.md) を参照。

## 3. マルチタイムフレームの使い分け

- 上位足（月足・週足）で**向き（バイアス）と大きな水準**を決め、下位足（日足、必要なら分足）で**タイミング**を測る。上位足と逆行する下位足のシグナルは、期待値が低いと考えるのが通例だが、これも検証事項。
- 足を変えるとパターンもトレンドも変わる。「どの足でその分析をしたか」を必ず記録に残す。
- 週足・月足は「期間が終わるまで確定しない」。期間途中の値を確定値として使うとバックテストで先読みになる（[チェックリスト](02_checklists_and_templates.md)）。

## 4. 指標の系統と冗長性

| 系統 | 主な指標 | 答える問い |
|---|---|---|
| トレンド | 移動平均線、ADX/DMI、パラボリックSAR、一目均衡表 | 上昇か下降か。どれだけ強いか |
| モメンタム | RSI、ストキャスティクス、MACD、CCI | 勢いは加速か減速か |
| ボラティリティ | ボリンジャーバンド、ATR、ケルトナー | 値幅は拡大か収縮か。損切り幅は |
| 出来高 | OBV、A/Dライン、CMF、VWAP | 値動きに資金の裏付けがあるか |
| 需給・センチメント | 信用残、空売り比率、投資部門別、日経VI | 売り手・買い手の偏りは |

原則は**各系統から1つ**。RSI・ストキャスティクス・CCI は同じ「直近の終値の位置」を別の式で見ているだけで強く相関する。同系統を重ねて「複数の指標が一致した」と数えるのは、確認ではなく重複である。

## 5. 日本株チャートに特有の注意（要約）

詳細・確認日は [東証の制度とチャート](../02_japan/04_tse_market_rules_and_chart_effects.md) を参照。

- 値幅制限（ストップ高・安）と特別気配: 張り付いた日は終値が需給を表さず、約定もできない。
- 呼値の単位（ティックサイズ）と売買単位: 低位株ほど価格の刻みが粗く、ポジションサイズは単元の整数倍にしかできない。
- 権利落ち・分割・併合: 調整後価格かどうかで、価格水準に依存するルール（キリ番、呼値、価格フィルタ）の結果が変わる。
- 決算・材料: 引け後発表が多く、翌日の始値で窓が空く。窓はギャップの典型で、損切り注文は窓の先で約定する。
- 信用取引の期日・空売り規制・逆日歩など、需給に直接効く制度がある。
- 指数の入れ替え・先物のSQ週など、チャートの形と無関係な売買が値動きを作る日がある。

## 6. よくある失敗

1. **後知恵でチャートを読む**: 結果を知った後に「ここがサインだった」と線を引く。事前に条件を書かなければ検証できない。
2. **都合のよい線・パターンを選ぶ**: 同じチャートに複数の読みが成り立つとき、ポジションを持った方向に合う読みを採用する。
3. **パラメータを過去に合わせ込む**: 期間・しきい値を最適化して成績を出す。別期間・別銘柄で崩れる（[検証手法](../03_evidence/02_methodology_behavioral_japan_ml.md)）。
4. **損切り幅が値動きに対して狭すぎる**: ボラティリティ（ATR）と無関係に決めた損切りは、通常の揺れで頻繁に執行される。
5. **同系統の指標を重ねて確信を深める**（4節）。
6. **流動性の無視**: 板が薄い銘柄で、想定したサイズ・価格で出入りできると仮定する。
7. **イベントの無視**: 決算・権利落ち・SQ・指数入れ替えをまたぐ判断を、通常日と同じチャート判断で行う。
8. **一度の成功体験を手法の有効性と取り違える**。取引回数が少ない結果は、運とスキルを区別できない。
9. **記録をつけない**ため、自分の判断の癖（早すぎる利確・損切りの先送りなど）を修正できない。

## 7. 手法を検証する手順（概要）

1. ルールを曖昧さなく文章化する（銘柄の選び方、シグナル、判定タイミング、約定の仮定、損切り・利確、ポジションサイズ）。
2. データを準備する（調整後価格、上場廃止銘柄を含める、出来高・売買代金）。
3. 期間を分ける（学習期間／検証期間、またはウォークフォワード）。検証期間は一度しか見ない。
4. コストを入れる（手数料、スリッページ、呼値、値幅制限での約定不能、信用の金利・貸株料）。
5. パラメータ近傍の頑健性、銘柄・期間を変えた頑健性を確認する。
6. 試したルールの数を記録し、多重検定の影響を考慮する。
7. 結果が弱い、または条件に敏感なら、採用しない。
