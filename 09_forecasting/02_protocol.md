# 予測手順（事前登録）— 日足による 1 週間・1 か月・3 か月先の確率予測
> 要約: トヨタ自動車（7203）と住友電気工業（5802）の日足から確率予測を作る手順を、**実際のデータを見る前に**固定した記録である。データの検査、幅（ボラティリティ）の予測、予測分布の作り方、候補モデル 10 個、チャートシグナル 41 個、評価指標、採否の基準、報告の様式、予測台帳を定める。数値はすべて実装（`07_reference_code/forecastlib`）と一致させてある。合成データでの自己検査の結果（偽陽性、検出力、区間の的中率）も載せる。データを見た後に手順を変えた場合は、8 節の変更履歴に理由とともに記録する。教育目的であり、投資助言ではない。
> 最終更新: 2026-11-11

## 1. 目的と、確度の測り方

- **予測の対象**: 基準日（CSV の最終日）の終値から、5・21・63 営業日後の終値までの対数リターンの分布。あわせて、期間中の高値・安値が指定の水準に届く確率。
- **確度の指標**: CRPS（分布全体。主指標）、50%・80%・90% 区間の的中率、上昇確率の Brier スコア、水準に届く確率の Brier スコア、ボラティリティ予測の QLIKE。指標の意味は [01_method_review.md](01_method_review.md) の 2 節。
- **比べる相手**: B0（過去の h 日リターンの分布をそのまま使う）と B1（EWMA のボラティリティで伸縮する）。
- **事前登録の意味**: 候補・パラメータ・基準を先に決めておけば、結果を見てから都合のよい仕様を選ぶ余地がなくなる。この文書を含むコミットの時刻が、データを受け取る前に手順が決まっていたことの記録になる。

## 2. データと前処理

- **入力**: 日足の CSV（日付・始値・高値・安値・終値・出来高）。Stooq 形式、Yahoo 形式、日本語の列名に対応する。文字コードは UTF-8 と CP932、区切りはカンマ・タブ・セミコロンを自動判定する。日付の昇順に並べ直し、重複した日付は後の行を残す。
- **検査**（`forecastlib/data.py`）: 四本値の欠損、0 以下の価格、高値・安値と始値・終値の矛盾、出来高 0、土日の日付、10 日を超える空白、同じ終値の 5 日以上の連続、最終日の古さ。四本値に欠損のある行は除く。0 以下の価格があれば中止する。
- **分割の未調整の検出**: 前日比の変化が ±31% を超える日を候補にする。東証の制限値幅は、基準値段 500 円以上では最大でも 30% なので [PJ-006]、これを超える日次変化は分割・併合の未調整かデータ誤りの疑いが強い。前日比が 1/1.5、1/2、1/3、1/4、1/5、1/10、1/20、1/25、1/50、1/100、2、5、10 のいずれかに対数で 0.15 以内なら、その倍率を推定値として示す。調整は、推定値を目で確かめてから `--split 日付:倍率` で指定する（`--auto-split` で自動適用もできるが、適用した内容はレポートに記録される）。
- **補助系列**（任意）: 指数・為替などの終値。`lag=0` は同じ日付までの値を使い（同じ取引時間の系列: 日経平均、TOPIX）、`lag=1` は前の日付までの値だけを使う（東京の大引けより後に終わる系列: ドル円の NY 終値、米国の指数）。既定は `lag=1` である。
- **学習のみの期間**: 最初の 1,250 営業日（約 5 年）は採点に使わない。履歴は 10 年以上が望ましい。2,000 行に満たない場合は検証できる期間が短く、結論の不確かさが大きいことをレポートに明記する。

## 3. 予測分布の作り方

記号: 終値 C、日次の対数リターン r_t = ln(C_t / C_{t−1})、先 h 日のリターン R_t = ln(C_{t+h} / C_t)。時点 t の量は、すべて t の終値までの情報で決まる。

### 3.1 幅（ボラティリティ）の予測

| 記号 | 内容 | 固定した値 |
|---|---|---|
| S1 | EWMA: v_t = λ v_{t−1} + (1−λ) r_t²。σ̂ = √(h·v_t) | λ = 0.94 [FC-004]。最初の 20 個の r² の平均で初期化 |
| S2 | HAR 型の対数回帰。目的変数は ln(先 h 日の実現分散 ÷ h)。説明変数は (1) レンジ系の日次分散の対数（当日、5 日平均、22 日平均）、(2) 下落の大きさ（当日のリターン、5 日・22 日の平均リターンの負の部分）、(3) 出来高の急増（当日と 5 日平均の、前日までの 60 日平均に対する対数比）。σ̂ = √(h × 予測値) | 結果が確定した行だけで最小二乗推定。21 営業日ごとに推定し直す。学習の最小行数 500。対数から戻す偏りは残差の exp の平均で補正。分散の床 2.5×10⁻⁷ |
| S3 | S1 と S2 の幾何平均 | 重みは推定しない |

レンジ系の日次分散は v_t = ln(O_t/C_{t−1})² + 0.5·ln(H_t/L_t)² − (2ln2−1)·ln(C_t/O_t)²（前日終値から当日始値への窓を含む形）。四本値に矛盾があれば r_t² で代える。出来高の列がなければ (3) は使わない。

### 3.2 予測分布

- **過去平均**: m_t = その時点までの r の平均（250 個以上あるとき）。
- **標準化リターン**: z_t = (R_t − h·m_t) / σ̂_t。使うのは、結果が確定した行（t + h ≦ 現在）だけである。
- **予測分布**: h·m_T + σ̂_T ×（z の経験分位点）。分位点の格子は 100 点（0.005、0.015、…、0.995）。
- **有限標本の補正**: 分位点の水準 τ を τ' = τ − (1−2τ)/(2N) に置き換える。N は有効な標本数で、1.5 × 標本数 ÷ h とする（h 日リターンは互いに重なるため）。類似局面の近傍では、時間的に h 日より離れた近傍のかたまりの数を N とする。

### 3.3 傾き（方向の材料）

特徴量は、その時点までの平均・標準偏差で標準化し（250 個以上あるとき）、±5 で打ち切る。σ1 は S1 の日次の標準偏差、sd_n は直近 n 日の r の標準偏差である。

| 特徴量 | 定義 | 使う候補 |
|---|---|---|
| mom63、mom126、mom252 | ln(C_t/C_{t−n}) ÷ (sd_n·√n) | T1、T3（mom126 は K1 も） |
| ret5、ret21 | ln(C_t/C_{t−n}) ÷ (σ1_{t−n}·√n) | T2、T3、K1 |
| ret1 | r_t ÷ σ1_{t−1} | K1 |
| kairi25、kairi200 | (C ÷ 25 日・200 日移動平均 − 1) を σ で割ったもの | T3 |
| rsi14c | (RSI(14) − 50) ÷ 20（ワイルダー平滑） | T3 |
| macdh | MACD(12,26,9) のヒストグラム ÷ (C·σ1) | T3 |
| adx_dir | ADX(14) ÷ 25 ×（+DI と −DI の大小の符号） | T3 |
| dd252 | ln(C ÷ 252 日の終値の最高値) ÷ (sd_252·√63) | T3、K1 |
| volr_signed | ln(出来高 ÷ 前日までの 20 日平均) × 当日のリターンの符号 | T3 |
| vol_trend | ln(出来高の 5 日平均 ÷ 60 日平均) | T3、K1 |
| gap | ln(O_t/C_{t−1}) ÷ σ1_{t−1} | T3 |
| ichi_pos | 一目均衡表の雲（9・26・52、26 本先行）に対して、上 +1・中 0・下 −1 | T3 |
| volstate | ln(σ1 ÷ sd_252) | K1 |
| 補助系列（名前_ret5、_ret21、_rel63） | 補助系列の 5 日・21 日リターン（σ 単位）、銘柄と補助系列の 63 日リターンの差 | X1 |

- **推定**: z を特徴量に回帰するリッジ回帰（定数項は罰則なし）。罰則は λ = h ÷ 0.05²（標準化した係数の事前の標準偏差を 0.05 と置くことに相当し、期間が長いほど強く縮小する）。結果が確定した行だけを使い、21 営業日ごとに推定し直す。学習の最小行数 500。
- **予測**: h·m_T + σ̂_T ×（傾き ＋ 残差の経験分位点）。
- **プール**: 他銘柄の日足があるときは、T1〜T3 の推定に他銘柄の行も加える。各銘柄の行は、結果の確定日が現在の日付以前のものだけを使う。X1 は補助系列を持つ銘柄だけで推定する。

### 3.4 類似局面と結合

- **K1**: 状態の特徴量（ret1、ret5、ret21、mom126、dd252、volstate、vol_trend）のユークリッド距離で、結果が確定した過去の時点から近い 150 個を選ぶ（候補が 600 個以上あるとき）。近傍の z の分位点と、全体の z の分位点を 50:50 で平均する。
- **E1**: V3・T3・K1 の予測分布を、分位点ごとに等しく平均する。

### 3.5 水準に届く確率

過去の各時点から h 日間の高値・安値を、ln(高値/C_t)・ln(安値/C_t) として σ̂_t（S3）で割って集める。水準 L に届く確率は、ln(L/C_T) ÷ σ̂_T を上回る（下回る）過去の割合とする。幅のモデルが B0 のときは、σ̂ で割らない分布を使う（B1・V2 のときも、標準化には S3 を使う）。検証では、σ̂ の 0.5・1.0・1.5 倍の水準について Brier スコアを計算する。

## 5. 評価と採否

- **ウォークフォワード**: 採点の開始は、1,250 行目か、S3 が計算できる最初の行の h+50 行後の、遅いほう。以後、毎営業日を予測の起点にする。全モデルが予測を出せた時点だけ（共通の標本）で比べる。
- **幅の段**: B0・B1・V2・V3 のうち、平均 CRPS が最小のものを選ぶ。同じなら単純なほう（B0、B1、V2、V3 の順）。傾きの候補は V3 の上に作ってあるので、幅の段で V3 以外が選ばれた場合、候補はそのモデルに勝たなければ採用されない。
- **傾きの段**: 候補（T1・T2・T3・X1・K1・E1）のうち平均 CRPS が最小のものを 1 つ選び、次の**すべて**を満たすときだけ採用する。満たさなければ幅の段の結果を最終モデルにする。
  1. Reality Check の p < 0.05（候補を複数試したことの補正。定常ブートストラップ、平均ブロック長 2h、2,000 回）
  2. 幅の段のモデルに対する DM 型検定の片側 p < 0.05（Bartlett 核の HAC 分散。ラグは 1.5(h−1) と 4(n/100)^(2/9) の大きいほう）
  3. 同じ比較の定常ブートストラップの p < 0.05
  4. 検証期間の前半と後半の両方で、平均 CRPS が改善
  5. 各時点の CRPS をその時点の S1 の σ̂ で割った値の平均でも改善
- **複数銘柄があるとき（パネル判定）**: 各銘柄に同じ手順を当て、各時点の CRPS をその銘柄の S1 の σ̂ で割ってから、日付ごとに銘柄平均し、同じ基準を適用する。他銘柄が 6 本以上あるときはパネル判定を主とする。2 銘柄だけの場合は、それぞれ単独の判定を主とし、互いをパネルにした実行は参考として併記する。
- **イベントスタディ**（チャートシグナル 41 個 × 3 期間、6 節）: 効果の大きさは、標準化した先 h 日リターンをシグナルに回帰して求める。検定は逆回帰（1 日の標準化リターンを、直近 h 日のシグナル点灯日数に回帰する [FC-001]。Newey–West のラグは平均 5、ばらつき 10）で行い、p 値は自由度を「シグナルのかたまりの数 − 1」とした t 分布で求める。点灯日が 20 日未満、かたまりが 8 個未満のものは「標本不足」とする。Benjamini–Hochberg の q 値 [FC-002] が 0.10 未満のものを「補正後も残った」と報告する。ばらつきへの効果は参考として扱う。**イベントスタディの結果は予測分布には直接使わない**（予測に入るのは、傾きの段を通った候補だけである）。

## 6. チャートシグナル（41 個）

その日の終値で確定する規則である。移動平均は単純移動平均、RSI はワイルダー平滑、σ1 は S1 の日次の標準偏差。

| 分類 | シグナルと規則 |
|---|---|
| トレンドの状態（13） | 終値が 25 日線・75 日線・200 日線より上（各 1）。25 日線が 75 日線より上。パーフェクトオーダー（5>25>75）とその逆。ADX(14)>25 かつ +DI>−DI、およびその逆。一目の雲の上・下。三役好転（転換線>基準線、終値が雲の上、終値が 26 日前の終値より上）と三役逆転。MACD ヒストグラムが正 |
| トレンドの出来事（6） | 25 日線と 75 日線のゴールデンクロス・デッドクロス（当日）。終値が 252 日の最高値・最安値。終値が前日までの 20 日の高値を上抜け・安値を下抜け |
| 行きすぎ（9） | RSI(14) が 30 未満・20 未満・70 超。終値がボリンジャーバンド（20、2σ）の下限未満・上限超。25 日線乖離率が −10% 未満・+10% 超。ストキャスティクスの Slow%K(14,3) が 20 未満・80 超 |
| 出来高（2） | 出来高が前日までの 20 日平均の 2 倍超で、当日が上昇・下落 |
| ローソク足（4） | 陽の包み足（下降後）、陰の包み足（上昇後）、ハンマー（下降後）、流れ星（上昇後）。形の定義は `chartlib/candles.py`、先行トレンドは 5 日 |
| 急変（7） | 直近 5 日に r_t/σ1_{t−1} が +3 以上の日・−3 以下の日がある。5 日リターンが σ 単位で +3 以上・−3 以下。終値が 252 日の終値の最高値の 60% 以下。始値の窓が σ 単位で +2 以上・−2 以下 |

## 7. 道具の検証

- **テスト**: `python -m pytest` で {{N_TESTS}} 件（うち forecastlib が {{N_FC_TESTS}} 件）。先読みがないことは、系列を途中で打ち切っても過去の予測分布が変わらないこと、将来の価格（自分と他銘柄）を書き換えても過去の予測が変わらないことで確かめる。
- **テストの検出力**: 先読みや計算の誤りをわざと入れた複製 14 通り（学習に未確定の行を使う、全期間の平均で標準化する、翌日の終値を使う、他銘柄の未来の行を使う、スコアの符号、多重検定の補正の省略など）で、14 通りすべてテストが失敗した。
- **自己検査**（`examples/forecast_selfcheck.py`。合成データで、実市場データではない）: ボラティリティが変動し裾の厚い日足（5,000 日）を作り、予測できる成分を入れない場合と、入れた場合を調べた。成分の強さ（係数）0.03・0.05・0.10 は、1 か月先のリターンの分散のそれぞれ約 2%・5%・23% を説明する大きさで、実際の市場で報告される大きさ（1% 未満が多い）より強い。

## 8. データを見た後に変えないこと、変更履歴

**変えないこと**: 期間（5・21・63 営業日）、3 節の式と数値、4 節の候補、5 節の指標と基準、6 節のシグナルの規則としきい値、学習のみの期間。結果を見てから、特徴量やシグナルを足したり、しきい値を動かしたり、成績の良い期間だけを使ったりしない。

## 9. 実行の手順

```bash
cd 07_reference_code
# 1 銘柄ずつ（主）。水準と、先の回答のシナリオ区間の確率も出す
python tools/forecast_report.py --csv <トヨタの CSV> --name "トヨタ自動車 (7203)" --out out/7203 \
    --scenarios ../09_forecasting/scenarios/7203_prior.json --ledger ../09_forecasting/ledger/forecast_ledger.csv --today <基準日>
python tools/forecast_report.py --csv <住友電工の CSV> --name "住友電気工業 (5802)" --out out/5802 \
    --scenarios ../09_forecasting/scenarios/5802_prior.json --ledger ../09_forecasting/ledger/forecast_ledger.csv --today <基準日>
# 補助系列があるとき（日経平均は lag=0、ドル円は lag=1）
#   --aux nikkei=<CSV>:0 --aux usdjpy=<CSV>:1
# 他銘柄があるとき（プール推定とパネル判定）
#   --panel <CSV> <CSV> ...
```

- **出力**: `report.md`（結論、データの検査、予測分布、水準に届く確率、シナリオ区間の確率、検証、イベントスタディ、過去の似た局面、限界）、`forecast.json`、図 2 枚、表の CSV。
- **予測台帳**: 予測を出すたびに `09_forecasting/ledger/forecast_ledger.csv` に行を足す（銘柄、基準日、期間、採用モデル、分位点 7 個、上昇確率、データの sha256、コードの版）。5・21・63 営業日後に、新しい日足で `forecastlib.ledger.score_ledger` を実行して採点する。
- **先の回答との関係**: 2026-11-11 の回答で主観的に付けたシナリオの重みを、`scenarios/*.json` に区間として記録した。レポートは、同じ区間に期間末の終値が入る確率を、今回の予測分布から計算して並べる。基準日が違うので、同じ条件の比較ではなく更新である。

## この文書の限界
- 事前登録は、結果を見てから仕様を選ぶ余地をなくすが、決めた仕様そのものが最良であることは保証しない。固定した数値（λ=0.94、事前の標準偏差 0.05、近傍 150 個、有効標本数の係数 1.5 など）は、文献の慣行と合成データでの確認に基づく選択である。
- 自己検査の合成データは、実際の株価の性質（決算の跳び、値幅制限、長い記憶、構造変化）を持たない。偽陽性や検出力の数字は、道具が設計どおり動くことの確認であり、実データでの性能の保証ではない。
- 検証は終値で採点し、取引コストを考えない。売買ルールの損益の検証ではない。
- 使うのは日足だけである。決算日・材料・板情報・信用残などは、補助系列として与えない限り入らない。次の決算のような予定された出来事は、過去の平均的な頻度でしか織り込まれない。
- 過去に似た例が少ない局面では、「過去の標準化した値動きの分布が今後も当てはまる」という前提が弱くなる。レポートはその度合いを表示するが、補正はしない。
